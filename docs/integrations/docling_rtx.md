[Docling RTX](https://github.com/codyvolckmar/docling-rtx) sets up Docling on a Linux machine with an NVIDIA GPU, such as a rented GPU pod, with one command.
It installs Docling on CUDA PyTorch and adds a drag-and-drop web page and a drop folder that convert PDFs, Office files, HTML and images to DoclingDocument JSON.
It can also serve [granite-docling-258M](https://huggingface.co/ibm-granite/granite-docling-258M) with vLLM, following the [RTX GPU guide](../getting_started/rtx.md).
