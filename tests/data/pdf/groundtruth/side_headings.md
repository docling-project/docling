## FIELD SERVICE SUPPLEMENT

This supplement covers the bench checks for revision B units. Each section heading sits in the left margin, level with the first paragraph it introduces.

## Package Contents

Your service kit should contain this supplement, a printed checklist and the sealed calibration certificate. Confirm that all three items are present before you begin, and report any missing component to the depot.

Do not start a service call with an incomplete kit. A missing certificate means that the readings you take cannot be filed.

## Tools Required

A workstation able to run the diagnostic console is needed, along with the standard probe kit for this revision and a calibrated torque driver.

A colour monitor is required so that the fault codes can be read during the bench checks. Use a grounded bench supply, and keep the capacitor discharge tool within reach before any panel on the chassis is opened.

## Setup and Checks

Remove the four access screws and lift the cover clear, then inspect the ribbon cable for wear along its full length. Reseat the main connector and refit the cover.

Torque the screws to the value printed on the chassis label. Restore power, run the self-test, and record the result in the maintenance log before returning the unit to service.

Keep the removed screws in the tray on the bench. A screw that falls into the chassis must be recovered before power is restored.

## Fault Codes

If the self-test reports a fault, note the code shown on the front panel and look it up in the table at the back of this supplement before you replace any part.

Most faults are caused by a loose connector. Reseat every connector on the main board once before you order a replacement board from the depot.
